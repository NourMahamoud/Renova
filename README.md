# ♻️ RENOVA

> *Everything has value.*

RENOVA is a sustainability-focused mobile marketplace application that gives unused items a second life instead of letting them become waste.

The app combines **Thrifting**, **Upcycling**, and **Donation** into one platform to encourage sustainable living and conscious consumption.

---

# 🚀 Overview

Every year, millions of usable items end up in landfills — not because they have lost their value, but because people no longer see their potential.

RENOVA was created to solve this problem by helping users:

* Sell unused items
* Discover creative upcycling ideas
* Donate items to people and organizations in need

Our mission is simple:

> Reduce waste. Encourage reuse. Create impact.

---

# ✨ Features

## 🔁 Thrifting

* Upload second-hand items for sale
* Add images and item details
* Browse affordable used products

## ♻️ Upcycling

* Discover creative ways to transform old items
* Explore sustainability-focused ideas
* Encourage reuse instead of disposal

## 🤝 Donation

* Donate unused items easily
* Connect with charities and organizations
* Support communities while reducing waste

## 👤 User Experience

* Simple and user-friendly interface
* Easy navigation between app sections
* Smooth user flow from login to marketplace
